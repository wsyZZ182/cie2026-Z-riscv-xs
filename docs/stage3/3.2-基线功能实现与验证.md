## 一、基线定义

基线 = **标准 RVV 指令组合**实现与 vdot.vv 完全相同的点积功能（SEW=8、VLEN=128、结果写 vd 低 32 位）：

| 精度 | 指令组合 | 说明 |
|---|---|---|
| e8 | `vle8.v` + `vwmul.vv`(e8→e16) + `vwredsum.vs`(e16→e32) | 宽乘 + 宽归约，乘积/累加不截断，结果精确 32 位 |
| e16 | `vle16.v` + `vwmul.vv`(e16→e32) + `vredsum.vs`(e32) | 同上 |
| e32 | `vle32.v` + `vmul.vv`(e32) + `vredsum.vs`(e32) | 乘积 64 位高位截断（用例值不越界） |

对应官方 3.2 表述"vmul.vv + vredsum.vs 组合"：`vwmul.vv`/`vwredsum.vs` 分别是元素乘法与归约求和的 widening 扩展形式（RVV 1.0 标准指令）。

**与 vdot 单指令的关键差异**：

| 维度 | vdot.vv（专用单元） | 基线（指令组合） |
|---|---|---|
| 指令条数 | 1 条 | 3~4 条 + 3 次 vsetvli（vtype/vl 切换） |
| 乘法实现 | 专用 Booth/CSA 阵列（宽度自适应） | 向量 ALU 逐元素乘法（vwmul） |
| 归约实现 | Fused ReduceAcc（CSA 树 + 单次 CPA） | vwredsum 归约单元 |
| 中间状态 | 无（单条写回） | 需 v2/v4 中间寄存器 + vmv.s.x 清累加器 |

## 二、基线程序

`code/stage3/vdot-baseline/vdot-baseline.c`（nexus-am 应用，13 用例与 vdot-test 完全同输入同期望）。

e8 基线核心序列：

```c
vsetvli vl, n, e8, m1
vle8.v  v0, (a)
vle8.v  v1, (b)
vwmul.vv v2, v0, v1          // 8x8 -> 16 宽乘，v2/v3 组（LMUL=2）
vsetvli vl, x0, e32, m1
vmv.s.x v4, x0               // 清累加器低 32 位
vsetvli vl, n, e16, m2       // vl 必须恢复为 n（见下"关键修复"）
vwredsum.vs v4, v2, v4       // E16 向量归约 -> E32 标量（累加 v4 旧值）
vsetvli vl, x0, e32, m1
vse32.v v4, (c)              // 写低 32 位
```

## 四、与 K07 同口径的物理测量

为了让基线与 K07 可比，把基线拉进 **K07 同一条 ASAP7 物理流程**重测（不是 cell-only 估算）：

| 项 | 值 |
|---|---|
| 流程 | `flow_top20_iofix.tcl`：floorplan(util 40) → GP(density .5) → `estimate_parasitics -placement` → `repair_design` → `detailed_placement` → `report_checks` |
| 综合 | Yosys 0.70+225，full ABC，`flatten`，`asap7_rvt_tt_merged.lib`，无 `-D`（面积驱动） |
| 角 | ASAP7 RVT **TT**，0.7 V，25 °C，`time_unit=1ps` |
| 边界 | reg-Q → reg-D（与 K07 加输入寄存器壳后同类） |
| FO4 | 1 FO4 = **17.9578 ps** |

| 对象 | 模式 | arrival | FO4 | 面积 |
|---|---|---:|---:|---:|
| 原生 `vwmul`（VIMacU） | 动态 | **4885.7 ps** | 272.1 | 5223 µm² |
| 原生 `vwredsum`（Reduction） | 动态 | **2637.7 ps** | 146.9 | 1421 µm² |

说明：

- 早期曾把 K07 往 cell-only 靠、把基线留在含寄生流程，两者相差一个完整物理实现阶段，直接相除会把 K07 优势低估约 1.5 倍。统一后 `vwmul` 从 cell-only 的 3191.9 ps 变为含寄生的 4885.7 ps。
- 两个对象在 1000 ps 周期下均未收敛（WNS 分别 −1637.7 / −3907.9 ps），只做相对比较，不是签核。
- 面积为标准单元总面积，不含布线金属、时钟树（未做 CTS）、IO pad、SRAM macro，也不含 whitespace；ASAP7 为预测性 PDK，绝对 µm² 不可迁移，只有比值可参考。

这两组数是 `3.3-延迟加速比分析.md` §1 路径比的**分母**。
