- **香山版本**：xs-env（XiangShan + yunsuan 子模块，kunminghu 分支）
- **仿真器**：`$NOOP_HOME/build/emu`（Verilator 编译，含 vdot 自定义指令）
- **运行方式**：`./build/emu -i build/vdot-test-riscv64-xs.bin --no-diff`
- **测试程序**：`nexus-am/apps/vdot-test/vdot-test.c`（7 用例，内联汇编发射 `vdot.vv` 编码 `0x12103157`）
- **最终日志**：`logs/stage2/vdot-test-final.log`

## 3. 测试覆盖说明

- **正数**：验证基本点积正确性（用例 1、5、6）。
- **负数**：验证有符号乘法与符号扩展累加（用例 2、7）。
- **边界值**：验证最大值（127）、最小值/零语义与饱和不溢出（用例 3）。
- **vl 截断**：验证 vl < 全元素时的部分归约（用例 4）。

## 4. 验证过程与修复记录

| 阶段 | 现象 | 根因 | 修复 |
|---|---|---|---|
| 编码冲突 | 输出恒 0，差分"通过" | 编码 0x12104157 与 `vminu.vx` 冲突，被译码为 `min(v1,0)=0` | 改 funct3=100→011，新编码 0x12103157 |
| 仿真超时 | 60s 报死锁 | vdot 大组合逻辑（16 Booth 乘法器 + CSA 树）使仿真慢约 5 倍 | 超时改为 ≥300s |
| e8 负数错 | 1048440 ≠ -136 | sumE8 零扩展累加，负数乘积被当正数 | 改符号扩展 `Cat(Fill(112, prod(15)), prod)` |
| e32 混合错 | -1184308404 ≠ -128 | Karatsuba 32 位负数路径位宽截断缺陷 | e16/e32 改 Chisel 原生乘法器 |
| slotMask 截断 | 2032 被截成 240 | slotMask 按 SEW 截断（e8 只留 8 位） | slotMask 固定低 32 位 |

## 5. 已知限制

- 差分测试（DiffTest）未启用：vdot.vv 为自定义指令，NEMU 参考模型不识别该编码，2.3 以 `--no-diff` 模式结果为准。
- 仅支持 LMUL=1（单向量寄存器）场景；元素按 SEW 全展开（e8:16 个 / e16:8 个 / e32:4 个）。
