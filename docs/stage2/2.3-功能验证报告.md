
## 3. 测试覆盖说明

- **正数 / 负数 / 边界**：比赛 2.3 三项要求全覆盖（2.3.1 五例、2.3.2 六例、2.3.3 八例，共 19 例）。
- **符号组合**：正正、全负、单边负、双负得正、正负交替、随机混合符号六类都覆盖（§2.2）。
- **边界与回绕**：全零、±极值（127 / −128）、最大幅值乘积（−128×−128）、`vdOld` 取 `0x7FFFFFFF`/`0xFFFFFFFF` 的模 2^32 回绕共 8 例（§2.3）。
- **参考模型独立**：期望值由独立 C++ 有符号点积模型计算，不复用 DUT 任何内部信号，避免同源自证。
- **多 seed 复现**：20 个 seed，每 seed 19 例，合计 380 次执行，全部 `pass=19 fail=0`。
- **vl 与 mask**：模块级无 vl 端口、mask 恒 `0xFFFF`，这两类由整核覆盖（e8 vl=4/1/0，§2.5）。
- **回归保障**：与香山原 13 项用例中 5 项同向量对齐（§2.6），保证与整核结果同口径。
- **与 2.4 互补**：本报告为功能级验证（点积数值与边界）；`2.4-Karatsuba乘法器算法对比.md` 为算法级验证（16/32 位乘法器边界全组合 + 4 万随机用例零错误），并给出乘法器选型的面积/延迟证据。

## 5. 已知限制

- **模块级不是整核**：§2.1–§2.4 的 380 次执行是模块级 RTL 仿真，vl / mask / E16 / E32 / vxsat / 背压 flush 六项能力不在该模块范围内，须以 §2.5 整核结果为据（对照表见 §3）。
- **窄 E8 变体 ≠ 交付版**：§2.5 的整核证据来自 `K07E8NextTop`（`fce32918…`），不是双模式 `K07`（`b854caed…`）；后者的整核结果见 §2.5 末段。
- **仅支持 LMUL=1**（单向量寄存器）场景；元素按 SEW 全展开（e8:16 / e16:8 / e32:4）。
- **vxsat CSR 读回受限**：香山 MinimalConfig 下 `VPUSubModule` 中 vxsat 写回链路被整体注释（标准 RVV 饱和指令同样不写 CSR）。VDotCore 内部 vxsat 信号逻辑正确（`full(31) ^ full(32)`，用例 13 已触发），CSR 读回受配置裁剪限制，vxsat 以 RTL 信号为准。
- **前身阶段曾关闭差分**：`VDotCore` 集成版的 emu 以 `--no-diff` 运行——当时 NEMU 参考模型尚未支持 vdot 编码（其扩展于 `docs/stage3/3.1-NEMU-vdot-指令扩展与协同仿真验证.md` 完成）。K07 阶段已启用 NEMU DiffTest，13 项零失配（§2.5）。
- **前身 `VDotCore` 的验证已不再维护**：§4.2–§4.4 的记录仅作演进参考，新增用例只在 K07 上跑。
